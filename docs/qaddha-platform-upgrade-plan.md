# Qaddha Platform Upgrade Plan

This branch is reserved for the staged stability-first upgrade requested for Qaddha / قدّها.

## Phase 1
- Quick Play
- Favorites
- Recently Played
- Saved Teams
- More section

## Phase 2
- Pre-game lobby
- Rematch
- Round summary
- Final results
- Question non-repetition

## Phase 3
- Resume game
- Session recovery
- Sound effects
- Haptics
- First-time tutorials

## Phase 4
- TV mode
- Unified host dashboard
- QR room connection
- Realtime synchronization

## Phase 5
- Party mode
- Session duration modes (15 / 30 / 60 minutes)
- Daily challenge
- Achievements

## Guardrails
- Preserve the approved Qaddha visual identity.
- Do not add more games during this phase.
- Do not remove working features.
- Do not force host/teams/timer/QR onto games that do not need them.
- Re-test any game touched by a platform feature.
- Keep unstable experimental behavior off the public home screen until verified.
