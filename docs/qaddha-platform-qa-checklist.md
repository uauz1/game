# Qaddha Platform QA Checklist

Use this checklist before merging each phase.

## Global
- Desktop
- Mobile
- Tablet
- Large display / TV mode
- Refresh during active session
- Back navigation
- Resume / restore state
- End game
- Rematch

## Hosted games
- QR renders
- Short room code works
- Host joins from second device
- Host disconnect/reconnect
- Public screen hides private answers
- Host controls sync to public display

## Game regression
For every touched game:
- Opens successfully
- Setup works
- First round starts
- Answer path works
- Score updates
- Timer works where applicable
- Next round works
- Finish screen works
- Rematch works
- No permanent loading state
- No dead buttons
